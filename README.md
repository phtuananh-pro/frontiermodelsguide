# Frontier Models guide (FMg)

**Understanding frontier AI from first principles.**

**Read the guide:** https://frontiermodels.guide

The **Frontier Models guide (FMg)** is a freely accessible technical guide to frontier models and the systems built around them. It develops durable understanding of fundamental problems, mechanisms, mathematical relationships, and system boundaries rather than cataloguing rapidly changing products and tools. **English is the authoritative reference edition.**

## About this repository

This is FMg's **official public publication repository**. It provides publication information, the version history, licensing terms, and channels for reader feedback and corrections.

The repository **does not contain the guide's Markdown files or the website's source code**. It is not the production workspace or an open-source collaboration project. Code examples linked from the guide are maintained in separate repositories under their own terms.

For the guide's scope, hybrid human-AI production process, limitations, and editorial responsibility, see the [Preface](https://frontiermodels.guide/en/preface).

## Versions and changelog

FMg is a living publication. The **[CHANGELOG](./CHANGELOG.md)** records significant published changes to both **FMg** and the **Website**, beginning with the first official publication.

- **FMg:** Uses custom editorial versioning, `Major.Minor.Patch`, for changes to the overall structure, chapters, and content. These numbers do not express software compatibility.
- **Translations:** Each translated language has its own `.Translation` revision, tied to a specific English edition. Published translations may temporarily follow different English source editions.
- **Website:** Uses an independent version sequence, starting at `1.0`, for meaningful changes to the reading and publication experience.

Changes to one do not automatically change the versions of the others. The CHANGELOG defines the complete versioning policy and release history; private development iterations and routine internal changes are excluded.
